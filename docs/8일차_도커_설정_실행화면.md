## docker-compose 실행

### `docker compose up --build`

`docker-compose.yml`을 통해 fastapi, mysql 두 서비스가 함께 실행되는 모습입니다.

<img src="assets/docker_compose_up.png" width="800" alt="도커 컴포즈 실행">

### 실행 환경 정보

| 항목 | 내용 |
|------|------|
| 실행 명령어 | `docker compose up --build` |
| FastAPI 서비스 포트 | `8000` |
| MySQL 서비스 포트 | `3306` |
| 볼륨 마운트 | `./:/app` |
| 코드 자동 반영 | `--reload` 옵션 적용 |
