# 5일차_Patient API 설계

# REQ-MDR-002 진료기록 목록 조회 API

## 1. API 개요

  -------------------------------------------------------------------------------------
  항목                                내용
  ----------------------------------- -------------------------------------------------
  API 이름                            진료기록 목록 조회 API

  설명                                로그인된 사내 개발진, 의료 실무진, 연구진은 환자
                                      상세 페이지에서 해당 환자의 진료기록 목록을
                                      조회할 수 있다.

  엔드포인트(Endpoint)                `/api/v1/patients/{patient_id}/medical-records`

  메서드(Method)                      `GET`

  인증 필요 여부                      Y
  -------------------------------------------------------------------------------------

------------------------------------------------------------------------

## 2. 요청(Request)

### Headers

  -------------------------------------------------------------------------
  Key                     Value                     설명
  ----------------------- ------------------------- -----------------------
  Authorization           `Bearer <access_token>`   로그인 사용자의 JWT
                                                    액세스 토큰

  -------------------------------------------------------------------------

### Path Parameter

  파라미터명   타입      설명
  ------------ --------- -----------------------
  patient_id   integer   조회할 환자의 고유 ID

### Query Parameter

없음

------------------------------------------------------------------------

## 3. 응답(Response)

### 성공

-   200 OK

``` json
[
  {
    "id": 101,
    "chart_number": "CH-20260720-0001",
    "symptoms": "기침과 발열이 지속되어 내원...",
    "created_at": "2026-07-20T09:30:00"
  }
]
```

  필드명         타입       설명
  -------------- ---------- ----------------------------
  id             integer    진료기록 ID
  chart_number   string     진료 차트 번호
  symptoms       string     증상(100자 초과 시 말줄임)
  created_at     datetime   생성일시

### 실패

-   401 Unauthorized
-   404 Not Found (환자를 찾을 수 없음)
-   504 Gateway Timeout (3초 초과)

------------------------------------------------------------------------

## 4. 비고

-   증상은 100자를 초과하면 `…`으로 축약한다.
-   최신 진료기록 순으로 조회한다.
-   로그인 사용자만 조회 가능하다.
-   NFR-MDR-001에 따라 최대 3초 이내 응답해야 한다.

------------------------------------------------------------------------

# REQ-MDR-003 진료기록 상세 조회 API

## 1. API 개요

  항목                   내용
  ---------------------- --------------------------------------------------------
  API 이름               진료기록 상세 조회 API
  설명                   로그인된 사용자는 진료기록 상세 정보를 조회할 수 있다.
  엔드포인트(Endpoint)   `/api/v1/medical-records/{record_id}`
  메서드(Method)         `GET`
  인증 필요 여부         Y

------------------------------------------------------------------------

## 2. 요청(Request)

### Headers

  -------------------------------------------------------------------------
  Key                     Value                     설명
  ----------------------- ------------------------- -----------------------
  Authorization           `Bearer <access_token>`   로그인 사용자의 JWT
                                                    액세스 토큰

  -------------------------------------------------------------------------

### Path Parameter

  파라미터명   타입      설명
  ------------ --------- -------------
  record_id    integer   진료기록 ID

------------------------------------------------------------------------

## 3. 응답(Response)

### 성공

-   200 OK

``` json
{
  "id": 101,
  "chart_number": "CH-20260720-0001",
  "symptoms": "기침과 발열이 지속되어 내원하였습니다.",
  "xray_image_url": "/media/xray/101.png",
  "created_at": "2026-07-20T09:30:00"
}
```

  필드명           타입          설명
  ---------------- ------------- -----------------------
  id               integer       진료기록 ID
  chart_number     string        진료 차트 번호
  symptoms         string        증상
  xray_image_url   string/null   흉부 X-Ray 이미지 URL
  created_at       datetime      생성일시

### 실패

-   401 Unauthorized
-   404 Not Found (진료기록을 찾을 수 없음)
-   504 Gateway Timeout (3초 초과)

------------------------------------------------------------------------

## 4. 비고

-   흉부 X-Ray 이미지는 이미지 저장 정책 확정 후 연동한다.
-   로그인 사용자만 조회 가능하다.
-   NFR-MDR-001에 따라 최대 3초 이내 응답해야 한다.

------------------------------------------------------------------------

# NFR-MDR-001 API 성능

-   모든 진료기록 API는 최대 **3초 이내**에 응답해야 한다.
-   구현 시 `asyncio.timeout(3.0)`을 적용하여 3초를 초과하면
    `504 Gateway Timeout`을 반환한다.
